# Defect register (Phase 1, static)

Commit audited: `92974ba` (PR #4 head). `M/` = `inst/shiny/modules/`. AT = Atlantis source `BethAtlantis_fix/atlantis` (16792e4).

## Status values

- **CONFIRMED**: checked against the Atlantis source **and** a real Atlantis output file, or reproduced.
- **CONFIRMED (source)**: the code was compared line by line with the Atlantis source. It has not been run.
- **SUSPECTED**: found by reading the code only. Needs a run or a reference calculation.
- **REFUTED**: contradicted by evidence.

Nothing has been executed in R yet; see the environment blocker in `README.md`. "Regression test" is "none" for every entry until Phase 8.

## Severity scale

- P0: scientific misinformation or a systematic indexing error.
- P1: an incorrect diagnostic or a misleading plot.
- P2: a localised defect or a usability problem.
- P3: minor.

| ID | Claim | Evidence |

| R-01 | "Layer padding is reversed: Atlantis pads shallow boxes at high z" (an agent's reading of attracerIO.c). | Real NESP output.nc from the same Atlantis build: z has length 7, with sediment at z = 6 and the surface at z = 5 in every box.
