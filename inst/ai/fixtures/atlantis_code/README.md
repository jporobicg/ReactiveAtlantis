not excerpts from the Atlantis ecosystem model repository. Function names are
deliberately prefixed with `fixture_` so they cannot be mistaken for a

Point the `fixture-atlantis-code` (or a renamed) source in the manifest at a
real Atlantis checkout when it is available. Record that tree's version or
commit in the manifest `version` field.
